# Artwork

`tomato-badges.png` is the original 4 × 3 illustration sheet supplied by the project owner for TomatoLock. It is embedded unchanged; WPF selects each cell at runtime. Row-major mapping:

1. First tomato; 2. Sprout; 3. Scholar; 4. Rocket; 5. Basket; 6. Wizard;
7. Three-day streak; 8. Seven-day streak; 9. King; 10. Silicon; 11. Rotten; 12. Office.

Sound effects are original synthesized PCM melodies generated locally by `TomatoArt.cs`; there are no external music downloads.
